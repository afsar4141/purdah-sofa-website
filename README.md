🏠 Purdah & Sofa — Full-Stack Furniture Service Platform

A modern full-stack web platform for Purdah, Curtains, Sofa, and Home Furniture services, designed to help customers explore services and submit enquiries while providing a backend system to manage customer requests.

🔗 Live Demo: https://purdah-sofa-website.vercel.app/

🔗 GitHub: https://github.com/afsar4141/purdah-sofa-website

📌 About The Project

Purdah & Sofa is a full-stack website built for a real-world home furnishing service business.

The platform provides customers with a simple way to:

Explore Purdah and Curtain designs
Discover Sofa and furniture services
View different furnishing categories
Submit their requirements through an enquiry form
Contact the service provider for customized requirements

The project is designed with a separate frontend and backend architecture, making it easier to maintain, extend, and deploy the application.
